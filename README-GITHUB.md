# مؤسسة مثابة — نسخة GitHub النهائية

هذه نسخة React/Vite ثابتة من موقع مؤسسة مثابة، جاهزة للرفع إلى GitHub وتشغيلها عبر GitHub Pages. تتضمن الهوية البصرية العربية RTL، الرأسية المتجاوبة، البطل الدعائي، الخدمات، معرض الأعمال الحقيقي، الفلاتر، Lightbox، قسم «خبرة تُرى في التفاصيل»، شريط الاتصال العائم، رسالة واتساب المسبقة، سمات التحويل لـ Google Tag Manager، حركة التحميل، Tooltip، زر العودة للأعلى، وGTM بالحاوية `GTM-WR4L54NC`.

## التشغيل محليًا

يتطلب المشروع Node.js 22 وpnpm 10. بعد تنزيل المستودع، شغّل:

```bash
pnpm install
pnpm dev
```

لفحص الأنواع وبناء نسخة الإنتاج:

```bash
pnpm check
pnpm build
```

توجد ملفات الإنتاج في `dist/public`.

## الرفع إلى GitHub Pages

أنشئ مستودعًا جديدًا على GitHub، ثم ارفع محتويات هذه الحزمة إلى فرع `main`. من إعدادات المستودع اختر **Settings → Pages**، ثم اجعل مصدر النشر **GitHub Actions**. سيقوم الملف `.github/workflows/deploy.yml` بتثبيت الاعتمادات، فحص TypeScript، بناء الموقع، ثم نشره تلقائيًا.

بعد نجاح العملية سيظهر رابط الموقع في قسم **Settings → Pages**. إعداد Vite يستخدم مسارات نسبية، لذلك يعمل الموقع داخل رابط مستودع فرعي أو نطاق مخصص.

## ملاحظات مهمة

الصور والشعار مضمنة محليًا داخل `client/public/assets` حتى لا تعتمد النسخة على تخزين Manus. تم الإبقاء على الصور الحقيقية المستخدمة في المعرض دون استبدالها بصور عامة. قسم المراجعات لا يحتوي شهادات مختلقة؛ أضف الشهادات الحقيقية فقط بعد موافقة أصحابها.

توجد شيفرة Google Tag Manager في `client/index.html`. يجب إنشاء ونشر العلامات والمشغلات داخل حساب GTM نفسه، ثم اختبارها عبر وضع Preview. تُستخدم سمات مثل `data-gtm-event` و`data-cta-location` لتمييز نقرات الهاتف وواتساب.

تظل ترويسات HTTP مثل `X-Frame-Options` و`X-Content-Type-Options` من مسؤولية الاستضافة أو إعدادات النطاق، ولا يكفي وضعها كـ meta tags داخل HTML.
